# TUOUGM Brand Guidelines

この文書は、TUOUGMのブランド表現に関する確定事項と、今後検討するデザイン案を記録します。デザイン案は構想段階のバックログであり、現在のサイトへの実装指示ではありません。

## 公式ブランドコピー

> **Born from Hardcore. Built on Gunpla. Driven by Noise.**

日本語訳：

> ハードコアから生まれ、ガンプラによって形作られ、ノイズを原動力に進む。

「Hardcore」は意図的に広義の表現として使用します。公式コピーに「Punk」は追加しません。

## ブランドの3つの軸

1. **Music First** — Hardcore Punk、Thrash Metalをルーツに、Industrial Metalなど幅広い音楽性を展開します。
2. **Gunpla Culture** — ガンプラ文化、模型制作、積みプラ、独自の世界観を創作の中心に置きます。
3. **Creative Evolution** — AIやデジタル技術は表現手段として扱い、作品そのものを主役にします。

## 音楽的バックグラウンドと表現の位置づけ

TUOUGMの音楽的背景には、1980年代のハードコアパンクシーンでの実活動経験があり、10代でのレコードリリース経験も含まれます。Hardcore PunkやThrash Metalのルーツを持ちながら、現在はIndustrial Metal、電子音楽的な質感、その他のヘヴィサウンドも取り入れています。

- 公式コピーの「Hardcore」は、Hardcore Punkだけに限定せず、ハードコアテクノなども連想できる広い意味で用います。
- 音楽的ルーツを具体的に説明する文脈では「Hardcore Punk」を使用して構いません。
- 過去の経歴は作品の背景や説得力を伝える材料であり、毎回の投稿で前面に出す必要はありません。
- AIは制作・表現の手段のひとつです。「AIで作った音楽」という技術面だけでブランドを定義せず、楽曲と作品世界を中心に伝えます。

## ブランド表現のガードレール

- 「Gunpla Band」はプロジェクトの独自性を伝える呼称として使用できますが、「World's First Gunpla Band」など、検証が必要な世界初・唯一といった断定は原則避けます。
- 楽曲ごとにジャンルが異なるため、すべての曲を一律にIndustrial Metalと説明しないようにします。
- Gunpla CityやRE:NAなどの物語表現と、制作者本人の実際の経歴は混同せず、文脈に応じて使い分けます。
- 誇張よりも作品の魅力を優先し、宣伝文でもTUOUGMのユーモアや実験性を損なわないようにします。

## 今後のデザイン方針（構想段階）

次回のサイトリニューアル時に、以下の方向性をキービジュアル（KV）へ採用するか検討します。いずれも未確定で、現行サイトへの実装指示ではありません。

- タイポグラフィを主役にしたビジュアル
- 極太のコンデンスド書体
- 黒・白を基調に、赤をアクセントとして使用
- HARDCORE / GUNPLA / NOISE の視覚的な強弱
- SNS投稿画像や動画エンドカードへの展開

## SNS運用方針

媒体ごとに表現を最適化しつつ、ブランドの核は統一します。投稿の目的を明確にし、**認知拡大 → 興味喚起 → サイト訪問 → 楽曲再生 → ファン化** の導線を意識します。

単なるリーチや「いいね」だけでなく、リンククリック、サイト流入、楽曲再生なども評価対象とします。すべての投稿で直接流入を狙うのではなく、媒体ごとの役割に合わせて設計します。

| 媒体 | 主な役割 |
| --- | --- |
| Facebook | 音楽性、楽曲紹介、サイトへの流入 |
| Instagram | RE:NA、ビジュアル、世界観 |
| YouTube | MV、Shorts、楽曲体験 |

## 運用・改訂ルール

- この文書はブランドの共通基準として、サイト制作とSNS運用の両方で参照します。
- 「公式ブランドコピー」と「ブランドの3つの軸」は確定事項です。
- KVのタイポグラフィ案・配色・SNS展開案は構想段階であり、実装決定ではありません。
- 新しい施策や表現は、媒体に最適化しつつ、音楽的背景・ガンプラ文化・作品主役の方針と矛盾しないか確認します。

## コラム企画：TUOUGMのルーツを深掘りする（戦略方針・決定）

### 背景と目的

Facebookのガンプラ系グループでは、これまでの運用実感として、単純な楽曲・MVの告知よりも、書き手の主観や考察を含む記事のリーチが良かった。この傾向を活かし、TUOUGMの音楽的・文化的なバックグラウンドを掘り下げる読み物を継続的に企画する。

- **目的**：広告的な告知だけに頼らず、記事自体の読み応えを通じて認知・共感・会話を生み、興味を持った読者をTUOUGMの公式サイトや楽曲へつなげる。
- **基本姿勢**：実体験・個人的な視点・文化的な考察を中心にする。バンド宣伝は主役にせず、記事のテーマから自然にTUOUGMへ接続する。
- **配信の考え方（確定フロー）**：まずTUOUGM公式サイトにコラム全文を掲載する。その記事への導線として、Facebookの音楽系グループ（ハードコア／パンク／メタルなど）へ投稿する。内容に合う場合はガンプラ系グループも対象とする。グループのルールを守り、宣伝投稿の連投は避ける。
- **Facebook投稿の編集方針（確定）**：記事リンクだけを貼る告知はしない。冒頭に読者が関心を持つ体験談・意外な事実・問いを置き、短い読み物として成立させながら、記事の核心や考察の続きが気になって公式サイトへ進みたくなる構成にする。内容のないクリックベイトや不自然な引き延ばしは避ける。
- **基本導線**：公式サイトにコラム全文を公開 → Facebook音楽系グループ向けに導入文を最適化して投稿 → 興味を持った読者がサイトで続きを読む → 関連記事・関連楽曲へ自然に回遊する。
- **評価**：リーチだけでなく、コメントや議論、リンククリック、サイト流入、楽曲再生への波及を見て改善する。過去の傾向は運用上の観察であり、すべてのグループや投稿で同じ成果を保証するものではない。

### 編集上の注意

- 制作者本人の実際の経験とGunpla Cityのフィクション設定は混同しない。
- 過去の出来事・作品・音楽史については、主観と検証可能な事実を区別し、公開前に必要なファクトチェックを行う。
- 英語版を含め、Facebookグループの読者がTUOUGMを知らなくても楽しめる内容を目指す。
- 連載頻度、記事順、タイトル、各SNSへの展開方法は今後の編集会議で決める。

## レビュー連載：RECORDS THAT BUILT ME（決定事項）

- **シリーズ名**：RECORDS THAT BUILT ME
- **企画の軸**：1980年代にリアルタイムで聴いていたバンドや作品を、当時の体験と現在の視点から振り返る。一般的なバンド紹介や経歴の要約より、制作者自身の記憶・評価・音楽活動への影響を重視する。
- **記事の基本構成**：
  1. 当時の出会い
  2. 好きだった曲やアルバム
  3. 自分のバンド活動への影響
  4. 今、改めて聴いた感想
- **記事の分量**：1本あたり1,500〜2,500字程度を目安とする。
- **編集方針**：必ずしも作品やバンドを褒める必要はない。当時と現在で評価が変わっていても率直に書く。実体験・主観と検証可能な事実は区別し、事実関係は必要に応じて確認する。
- **位置づけ**：既存のルーツ・文化コラムと並行する音楽レビュー企画。公開順や対象バンド／アルバムは別途決定する。
