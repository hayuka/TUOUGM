## 企画意図

80年代日本のハードコアパンクを一般論として解説するのではなく、LOST FIGHTSを結成した当事者の個人的なキャリアを軸に、当時のインディーズレーベル、レコード、ライブハウス、交流したバンド、聴いていた音楽を織り交ぜる。

**主役は実体験。時代背景はエピソードから自然に見せる。** 最後に現在のTUOUGMへつなぐが、広告記事にはしない。

公式ブランドコピー: **Born from Hardcore. Built on Gunpla. Driven by Noise.**

## 想定読者

- 80年代日本のパンク／ハードコアを知る人

- TUOUGMの音楽的背景を知りたい人
- バンドやレコードの自主制作に関心がある若い読者

## 本文構成（案）

### 1. 導入 — 14歳、楽器も弾けないのにバンドを始めた

- 少年期に洋楽へ親しむ。小林克也『ベストヒットUSA』、ニューウェーブなどの音楽体験。
- パンク／ハードコアとの出会い。特にアメリカの **7 Seconds** に強く影響を受けた。
- 14歳頃、友人たちと **LOST FIGHTS** を結成。本人はベース、ボーカルは後にレゲエ／ラガマフィンの道へ進む **YOYO-C**。
- メンバーはまともに楽器を弾けず、コピーができないのでオリジナル曲を作った、という逆説的な出発点。
- 導入は当時の情景や具体的な一言から始める。百科事典風の歴史解説にはしない。

### 2. 最初のステージと横須賀のライブハウス

- 学校で「変な奴らが変な曲を歌っている」と噂になり、上級生の教室でほうきを楽器に見立てて演奏をまねた話。
- 最初の実際のライブは横須賀のライブハウス **Reverb**。同世代のパンクバンドと出演。
- 演奏は荒削りだが、ライブそのものに強い緊張はなかった。
- 当時のライブハウス文化、先輩バンドとの接点、フライヤーやチケットなどの実物資料があれば挿入。

### 3. 一本のデモテープと、ウォーターランド

- 自作デモカセットを持ち、アポイントなしで店に飛び込んだ。
- **ウォーターランド** はレーベル名ではなく、社長が営んでいた店の名前。中古電化製品やレコードを扱う、現在のセカンドハンズ店に近い業態だったという記憶。
- 店でデモを聴いた若い男性から演奏やメロディーに厳しい意見を受け、後で **FVKのギタリスト** だったと知る。
- その後、社長が「ああは言っているけど俺は好きだよ君たちの音楽」と言い、コンピレーション参加へつながった。
- **重要**: ウォーターランドと発売レーベル **MUSICAL FRIEND** は区別して記載。両者の運営上の関係は未確認。

### 4. レコードを出すということ — 80年代インディーズの現場

- スタジオ録音は楽器を一発録りし、ボーカルを別録り。エンジニアが未経験の少年たちを助けてくれた。
- ベースの音を「太くて硬く」と注文したら「それができりゃみんなそうするだろ」と返されたエピソード。
- 日本のコンピレーション盤 **『I'll Gather Up (Musical Friend Omnibus)』** にLOST FIGHTSが参加したという既出情報。レーベル名 **MUSICAL FRIEND**、規格番号等は公開前に現物・一次資料で再確認する。
- フランス盤 **『Panx Vinyl Zine 03』** への参加についても、発売年・曲名・レーベル・クレジットを要検証。
- 当時のレコード制作、流通、店頭販売、ライブ会場での販売などは、**本人が直接経験・記憶している範囲**から書く。一般的な仕組みを断定しない。

### 5. あの頃の音楽と人たち

- LOST FIGHTSはハードコアながら、比較的ポップで動きのあるベースラインも特徴だったという本人の認識。
- 当時好きだった **7 Seconds**、実際に聴いたレコード、交流したバンドを具体的に紹介する。
- 同時代の日本のシーンの雰囲気を、ライブや人間関係の体験から描写する。
- 優しい先輩もいれば怖い先輩もいた。後年の出来事をもってシーン全体を危険・反社会的と一般化しない。
- 同級生のドラマー **増田力也** から演奏・練習姿勢に大きな影響を受けた話は、本文に入れるか別記事へ展開するか検討。

### 6. 16歳、LOST FIGHTSの終わり

- YOYO-Cと本人がレゲエ／トースティングなど別の音楽にも興味を広げた。
- 音楽的な方向性と周囲の人間関係の違いなどが重なり、16歳頃に解散。
- その後も音楽活動を続けるが、生活面では荒れた時期もあった。美化せず、具体的な記述は本人の公開判断を優先する。
- 英国留学は本記事では転換点として簡潔に触れる。詳細は続編候補。

### 7. 終章 — 形を変えて残った衝動

- 英国でスラッシュメタルに熱中し、その後MV制作やデジタルロックの曲作りも経験。
- 育児期には約10年、作曲から離れたが、音楽への関心が消えたわけではない。
- ガンプラ動画制作を経て音楽制作を再開。現在の **TUOUGM** へ。
- **AIは新しい制作手段**。音楽経験をAIに置き換える説明にしない。
- 14歳の「コピーできないなら自分で曲を作る」という発想と、現在の創作を静かにつなぐ。
- 最後に公式コピーを配置する案。楽曲プレイヤーや関連曲への導線は控えめに。
