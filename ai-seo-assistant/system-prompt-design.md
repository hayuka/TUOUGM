# System Prompt / 出力トーン制御設計

## 目的

WordPress向けAI記事生成プラグインにおいて、生成の人格を固定し、ユーザーが指定したトーンで出力を制御する設計を定義する。

## 概要

現在の実装では、生成プロンプトに固定指示を埋め込む形で文章品質を担保している。これを明確に分離して、以下を実現する。

- `System Prompt` で生成の人格と基本ルールを固定する
- `モード` に応じて生成スタイルを切り替える
- `トーン` を選択できるUIを追加し、出力スタイルを制御する
- `Gemini API` 呼び出し時にプロンプトを分離して構成する

## 設計方針

### 1. プロンプトレイヤーの分離

生成リクエストは少なくとも2つのレイヤーで構成する。

1. System Prompt（固定人格・ルール）
2. User Prompt（キーワード・モード・トーン・出力フォーマット）

Gemini API では `contents` の各 `parts` に分けて送信し、モデル側に明確な指示を与える。

### 2. モードとトーンの役割

- モード：用途ベースの生成スタイル
  - `SEO Mode`：検索意図ベース、構造化されたSEO記事
  - `Concept Mode`：世界観・詩的表現、ブランド訴求
  - `LP Mode`：見出し構成重視、CVを意識した構成

- トーン：文章の表現スタイル
  - `標準`（Standard）
  - `ダーク`（Dark）
  - `詩的`（Poetic）
  - `テクニカル`（Technical）

## UI設計

管理画面「記事生成」タブに以下を追加する。

- トーン選択ドロップダウン
  - `standard`：標準
- `friendly`：親しみやすい
- `professional`：専門的・信頼
- `clear`：分かりやすい
- モード選択は既存の `記事タイプ` を引き継ぐ。

## プロンプト構成

### System Prompt（固定）

```
あなたは日本語のSEO記事編集者です。
以下のルールに従って出力してください。
- 読者にとって分かりやすい自然な日本語を使う
- 根拠のない断定を避ける
- WordPress投稿用の記事として作成する
- HTMLではなく、Markdown見出し記法とプレーンテキストで出力する
- 文章は途中で切れずに完結させる
```

### Tone 指示

システムプロンプトの後、またはユーザープロンプト内でトーン指示を追加する。

例:
```
出力トーン: ダーク
- 謎めいた表現を使う
- 感情的で強い語調を持たせる
```

### Mode 指示

```
生成モード: SEO Mode
- 検索意図を満たす構成と見出しを作成する
- 具体例と比較を含める
```
```

### User Prompt（生成内容）

```
キーワード: WordPress SEO, AI記事生成
記事タイプ: ブログ記事
出力形式:
タイトル:

本文:
```

## 実装設計

### 1. `PromptBuilder` クラス

新規ファイル: `ai-seo-assistant/includes/class-aiseo-prompt-builder.php`

このクラスは以下を担当する。

- 固定 System Prompt テキストを管理
- モード別の生成指示を返す
- トーン別の出力指示を返す
- キーワード・記事タイプを含むユーザープロンプトを組み立てる

### 2. 管理画面の拡張

既存 `ai-seo-assistant/templates/admin-page.php` にトーン選択を追加する。

- `select` 要素でトーンを指定
- `POST` で `generate_article` に送信

### 3. Gemini API呼び出しの拡張

`ai-seo-assistant/includes/class-aiseo-gemini-client.php` で以下を実装する。

- `build_prompt()` を `PromptBuilder` に委譲
- `contents` 配列を `system` と `user` の2つに分ける
- `maxOutputTokens` を保持しつつ、モードとトーンに応じたプロンプトを送信

### 4. デフォルトトーンと設定

トーン選択は初期値 `standard` とする。

拡張性を考えて、将来的にはトーンを管理画面でカスタマイズ可能な設定として保持できる。

## サンプル構成

### System Prompt

```
あなたは日本語のSEO記事編集者です。
以下のルールに従って出力してください。
- 読者にとって分かりやすい自然な日本語を使う
- 根拠のない断定を避ける
- WordPress投稿用の記事として作成する
- Markdown見出し記法を使う
- 文章は最後まで切れずに完結させる
```

### User Prompt

```
キーワード: WordPress SEO, AI記事生成
モード: SEO Mode
トーン: ダーク

条件:
- タイトルを1つ提示する
- 導入、見出し、本文、まとめを含める
- `タイトル:` と `本文:` ラベルは最終出力に含めない

出力形式:
タイトル:

本文:
```
```

## 期待効果

- 生成の人格が安定し、出力品質が向上する
- トーン選択により、ユーザーが狙った表現スタイルを得られる
- プロンプト実装の責務が明確になり、将来の拡張性が高まる
