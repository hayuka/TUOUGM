# AI SEO Assistant

## 目的

WordPressでAI記事を自動生成し、下書き保存するプラグイン

## 技術構成

* WordPress Plugin
* PHP
* Gemini API
* Gutenberg対応

## MVP機能

* APIキー設定
* Gemini接続テスト
* キーワード入力
* 記事タイプ選択
* AI記事生成
* WordPress下書き保存

## 将来機能

* Search Console連携
* 内部リンク自動生成
* FAQ生成
* タグ生成
* カテゴリ自動判定
* アイキャッチ生成
* SNS投稿文生成
